## 7. 外部依赖来源补充规则

若项目外部调用主要通过 `MeshTemplate` 发起，代码来源清单建议额外优先纳入：

- `MeshTemplate` 注入所在类
- `MeshTemplate` 实际调用点所在方法
- 基于 `MeshTemplate` 的包装类 / client 类 / 网关类
- 调用 `MeshTemplate` 的 service / 门面类
