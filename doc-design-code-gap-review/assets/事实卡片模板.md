# 事实卡片模板

## 通用结构

```markdown
- 事实编号：
  来源类型：
  文件路径：
  位置：
  对象：
  维度：
  事实内容：
  备注：
```

字段约束：

- 一张卡片只表达一个原子事实
- `来源类型` 只能是：`需求文档` / `技术文档` / `代码实现`
- `事实内容` 只写客观事实，不写结论
- 无法定位文件路径和位置时，不得生成正式卡片

## 示例

```markdown
- 事实编号：REQ-001
  来源类型：需求文档
  文件路径：docs/requirement/create-order.md
  位置：参数说明
  对象：fundCode
  维度：参数校验
  事实内容：fundCode 为必填字段
  备注：
```

```markdown
- 事实编号：DES-007
  来源类型：技术文档
  文件路径：docs/design/create-order-design.md
  位置：请求模型定义
  对象：fundCode
  维度：参数校验
  事实内容：fundCode 在请求 DTO 中标记为 required
  备注：
```

```markdown
- 事实编号：CODE-012
  来源类型：代码实现
  文件路径：src/main/java/com/example/CreateOrderRequest.java
  位置：第 22 行
  对象：fundCode
  维度：参数校验
  事实内容：fundCode 字段未声明 @NotNull 或等价校验
  备注：
```

## 外部依赖事实补充规则

若项目主要通过 `MeshTemplate` 调用外部依赖，代码事实优先抽取：

- `MeshTemplate` 注入点
- `MeshTemplate` 实际调用方法
- 基于 `MeshTemplate` 的包装类 / client 类 / 网关类
- 调用参数、返回值映射和异常处理逻辑

示例：

```markdown
- 事实编号：CODE-020
  来源类型：代码实现
  文件路径：src/main/java/com/example/ChannelQueryClient.java
  位置：queryStatus 方法
  对象：MeshTemplate.queryStatus
  维度：外部依赖调用
  事实内容：通过 MeshTemplate 调用渠道状态查询接口，并将返回值映射为 QueryStatusResponse
  备注：
```
