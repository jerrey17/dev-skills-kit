# 对齐矩阵模板

## 1. 使用方式

该模板按“审查对”复用。

可生成的矩阵包括：

1. `需求-技术对齐矩阵.md`
   - 基线层：需求
   - 对齐层：技术文档

2. `技术-代码对齐矩阵.md`
   - 基线层：技术文档
   - 对齐层：代码

3. `需求-代码对齐矩阵.md`
   - 基线层：需求
   - 对齐层：代码
