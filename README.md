# dev-skills-kit

dev-swarm 流水线会调用的阶段技能。每个目录可以单独使用，目录内的 `README.md` 说明用途、输入和产出，步骤在 `SKILL.md`。

## Skills

| Skill | 阶段 |
|---|---|
| req-analysis | 需求分析 |
| service-split | 服务拆分 |
| tech-solution-design | 技术方案 |
| tapd-wiki-publish | 技术方案推送到 TAPD Wiki |
| java-coding-workflow | 开发编码 |
| doc-design-code-gap-review | 方案与代码对齐 |
| java-code-review | 代码规范审查 |
| new-test-development | 单元测试 |
| submit-for-testing | 提测 |
| bug-fix | 缺陷修复 |
| flow-verify-four-step | 自动化测试四步法 |
| release-checklist | 发布清单 |
| workflow-learnings-to-kb | 复盘经验沉淀 |
| knowledge-base-update | 知识库索引更新 |
| gitnexus-cli | 代码索引命令 |
| gitnexus-exploring | 代码探索 |
| gitnexus-impact-analysis | 影响面分析 |
| gitnexus-debugging | 问题追踪 |
| gitnexus-refactoring | 安全重构 |
| gitnexus-pr-review | 变更审查 |
| gitnexus-guide | GitNexus 用法 |

示例里的路径、项目编号和包名都是占位符。token 只从参数、本地配置或环境变量读取。
